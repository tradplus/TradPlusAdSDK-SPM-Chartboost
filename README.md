# TradPlus Chartboost Adapter Swift Package

Swift Package Manager support for the TradPlus Chartboost adapter (15.12.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Chartboost.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Chartboost.git", exact: "15.12.0")
```

Third-party dependency: Chartboost SDK `9.13.0`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.12.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
